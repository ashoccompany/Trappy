1. WHAT IS TRAPPY?
================================================================================
Trappy is an expressive, universal, and modern programming language built from 
scratch to make software, 2D/3D games, distributed network clients, and offline tools 
accessible to everyone.

Guiding Principle: "Simple needs to be simple."
Beginners can create working games and network apps in minutes, while advanced creators 
can connect almost anything across the web and local systems without boilerplate.

Optimized for Ultra-Budget Hardware:
- Memory footprint under 30 MB idle.
- Frame throttling (`fps calm`) drops refresh rate when windows are out of focus,
  saving up to 90% CPU on budget laptops.
- Offline loopback bus enables multiplayer testing without network adapters.

4. DISCORD WEBHOOKS & UNIVERSAL CONNECTIVITY
================================================================================
Connect almost anything to Trappy in 1 line:

1. Send Discord Channel Webhook:
   txt "https://discord.com/api/webhooks/your_webhook_url" tit hook_url
   txt "Player TrappyKnight reached Level 10!" tit msg
   discord_webhook hook_url:msg tit status
   gan status

2. JSON Parsing & Serialization:
   dict tit profile
   dset profile:"score":5000
   json_dump profile tit json_text
   gan json_text

   json_parse json_text tit restored_profile
   dget restored_profile:"score" tit score_val
   gan score_val

3. WebSocket & Streaming Streams:
   ws_connect "ws://127.0.0.1:8080" tit stream
   ws_send stream:"Client Hello"
   ws_recv stream tit incoming
   ws_close stream

    gan player_gold

    dkeys inventory tit all_keys
    gan all_keys

6. LISTS & ARRAY INDEXING
================================================================================
    lst 10 | 20 | 30 eq scores
    lget scores:0 tit first_score       # 10
    lset scores:1:99                   # Updates 20 -> 99
    lpush scores:50                    # Appends 50 to list
    llen scores tit count              # Returns 4
    lpop scores tit last_val           # Removes and returns 50

8. PACKETS & CLIENT/SERVER NETWORKING (WITH OFFLINE LOOPBACK)
================================================================================
1. Data Packets:
   add_obj "sync_pkt"
       id: 101
       x: 250
       y: 180
   tren
   pack_data sync_pkt tit stream_pkt
   unpack_data stream_pkt tit restored

2. Offline Resilient Loopback:
   Connect to "loopback":port for offline multiplayer testing with zero internet:
   cli_connect "loopback":8080 tit client
   cli_send client:stream_pkt
   cli_recv client tit reply
   cli_close client

3. Live Client/Server:
   cli_connect "127.0.0.1":8080 tit client
   srv_listen 8080 tit server
   srv_accept server tit incoming_conn

11. MATHEMATICS, ALGEBRA & PHYSICS
================================================================================
Equations start with `mh` and store results with `eq`:

    mh 10 + 5 eq total
    mh sqrt 144 eq root             # 12.0
    mh pow 2:8 eq power             # 256.0
    mh abs -42 eq absolute          # 42.0
    mh clamp val:0:100 eq bounded   # Clamps between 0 and 100
    mh sin 30 eq s                  # 0.5
    mh cos 60 eq c                  # 0.5
    mh rnd 1:100 eq roll

2D Physics & Collision:
    # AABB Bounding Box Collision (returns 1 if intersecting, 0 otherwise)
    box_hit x1:y1:w1:h1 x2:y2:w2:h2 tit is_hit

    # Vector Math
    vec_add x1:y1 x2:y2 tit sum_vector
    vec_mag x:y tit length

12. 3D MULTI-SHAPE WIREFRAME GRAPHICS ENGINE
================================================================================
Trappy v1.0 features native perspective 3D rendering:

1. 3D Wireframe Cube:
   cube3d x:y:z size rx:ry color
   Example: cube3d 300:225:0 140 20:30 cyan

2. 3D Wireframe Sphere (Celestial 3-Ring Projection):
   sphere3d x:y:z radius rx:ry color
   Example: sphere3d 350:250:0 60 20:30 green

3. 3D Wireframe Pyramid (4-Sided with Apex):
   pyramid3d x:y:z size rx:ry color
   Example: pyramid3d 500:250:0 100 20:30 yellow

4. 3D Line in Space:
   line3d x1:y1:z1 x2:y2:z2 rx:ry color

PROGRAM 2: 3D ROTATING SHAPES ENGINE
--------------------------------------------------------------------------------
trst
    cwin "3D World" 700:500 main
    sbgwin "3D World" black
    fps calm

    mh 20 eq rot_x
    mh 30 eq rot_y

    gloop
        mh rot_y + 1 eq rot_y
        cube3d 200:250:0 100 rot_x:rot_y cyan
        sphere3d 380:250:0 50 rot_x:rot_y green
        pyramid3d 540:250:0 110 rot_x:rot_y yellow
        ifr key "W" trg then mh rot_x - 3 eq rot_x
        ifr key "S" trg then mh rot_x + 3 eq rot_x
    tren
tren
